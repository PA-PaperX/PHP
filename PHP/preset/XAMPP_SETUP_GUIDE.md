# คู่มือการรันโปรเจคสำหรับทีมที่ใช้ XAMPP

## วิธีการรันระบบเพื่อพัฒนาในเครื่องตัวเอง (Localhost)

### 1. การรัน Backend (ระบบหลังบ้าน)
ได้เตรียมสคริปต์ Preset ไว้ให้แล้ว ทำงานแค่คลิกเดียวจบ
1. เปิด **XAMPP Control Panel** และกด **Start** ที่บรรทัด **MySQL**
2. เข้าไปที่โฟลเดอร์หลักของโปรเจค หาไฟล์ที่ชื่อ `setup.bat` 
3. ดับเบิลคลิกไฟล์ `setup.bat` 
4. สคริปต์จะทำการสร้างฐานข้อมูล (iya_db), นำเข้าข้อมูล และรัน PHP Backend Server ให้ทันทีที่ **http://localhost:8080**
5. **ปล่อยหน้าต่างสีดำ (CMD) นี้ทิ้งไว้** ห้ามปิดจนกว่าจะเลิกทำงาน

### 2. การรัน Frontend (หน้าบ้าน)
โปรเจคนี้ใช้ Nuxt.js ในการทำหน้าบ้าน:
1. เปิดหน้าต่าง Command Prompt (cmd) หรือ Terminal ขึ้นมาใหม่
2. `cd` เข้าไปในโฟลเดอร์ `frontend` ของโปรเจค
3. หากเปิดครั้งแรกให้รันคำสั่ง `npm install` เพื่อลง Dependencies
4. รันคำสั่ง `npm run dev`
5. รอจนมันขึ้นว่ารันเสร็จ แล้วเข้าเว็บเบราว์เซอร์ไปที่ **http://localhost:3000** ได้
*(หากมีคำถามเรื่อง Telemetry ให้กดพิมพ์ y หรือ n แล้วกด Enter เพื่อให้มันรันต่อ)*
